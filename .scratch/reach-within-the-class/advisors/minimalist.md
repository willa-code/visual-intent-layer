# Independent review — minimalist interaction designer

Lens: lower the words, controls and steps the human meets; calmer and more beautiful. Added vocabulary, controls, modes and per-case sentences are guilty until they earn their place.

DECISION 1 — (b) Refuse, and never move the artifact ourselves; attribute the abstention to the state that is already recorded, not to the revision.
WHY: The operator can only point at what is rendered, so an unrendered row is never a pointing problem — it is a re-finding problem that surfaces at Verify, when the operator is present, looking at the list, and able to scroll as ordinary operating (`design.md:321-323` `V` is the unarmed state). Scrolling for them is the surface swapping the artifact out from under the open card and draft, which `design.md:249-253` and the anti-pattern at `design.md:456` forbid, and the product has never moved the artifact's view: nothing in `src/` calls a scroll method, scroll is only ever recorded (`src/ui/artifact/grounding.ts:83-84`, `:173-174`). Option (a) also buys almost nothing — scrolling to a recorded offset produces the row only if the list above it did not change, which is exactly what a revision changes. The cost of (b) as shipped is a false sentence: with no candidate the row reads "*X* is not in this revision" (`src/ui/app.ts:2067-2068`), untrue of a row that is in the revision and merely unrendered; so the abstention must fall to the derived label the product already owns, `state-only` (`src/resolution/model.ts:30-36` → `src/ui/app.ts:2065`), keyed on the recorded scroll as well as the recorded address. That is one clause added to an existing derived label (`CONTEXT.md:127-128` already names scroll as part of Runtime State Evidence) and zero words, controls or modes added; CONTEXT.md takes that clause, and no new vocabulary is minted.
BOLDER: Make the operator's own search the resolution. `src/ui/artifact/layer.ts:854` already listens for scroll at capture phase; re-running resolution on that event means scrolling to the row fixes the Annotation by itself — no re-point, no notice, no number, and the surface never moves the artifact once.

DECISION 2 — One budget, one order: 2000 nodes spent across the whole composed tree in a single fixed order, each document visited once; at the bound, stop and abstain — never resolve lower.
WHY: 2000 is already the shipped number and it is spent by two functions that must agree, because a candidate's id is its position (`src/ui/artifact/grounding.ts:200`, `:208`, `:235`) — a second bound applied in one and not the other re-binds `node-N` to a different node, which is a silent mis-point rather than a refusal. A depth number is unnecessary once each document is visited once: the proxy injects the artifact layer into every proxied `text/html` response (`src/service/http.ts:1318-1324`), so an artifact that embeds itself recurses by construction, and a visited-set stops that exactly where a depth cap stops it arbitrarily. A time bound is the one I reject outright: it makes the same target resolve or not depending on machine load, and a nondeterministic "could not find" is the worst state to hand an operator. The budget must be composed rather than per-document, or a 3000-node outer document starves the frame interior this spec exists to reach (`.scratch/reach-within-the-class/spec.md`, "Same-origin frames"). What the operator meets at the bound: nothing new — the existing unresolved state and its marked candidates (`design.md:236-238`, `src/resolution/resolve.ts:48`), never a sentence naming a bound they cannot raise, and never a lowered threshold (`src/resolution/resolve.ts:42-46`) that hides the weaker match (`design.md:419`, `:444`).
BOLDER: Stop enumerating what the pointer already handed us. The pointed node and its box are in hand; record its composed path — which frame, which host, which shadow root — as Rendered Grounding and re-find by walking that path. Re-finding becomes O(depth) instead of a fan-out, and the bound stops being a promise the operator could ever meet.

DECISION 3 — (a) A drawn Area encloses exactly what is geometrically inside it, across boundaries; nothing inside the rectangle is ever refused because of where it lives.
WHY: The Area is the one target that needs no cooperation from the artifact (`CONTEXT.md:115-116`), and its meaning is spatial — the operator draws a rectangle, not a scope (`design.md:321-322`). Option (b) makes the surface state something false: the Area's label is derived from what it enclosed (`src/ui/artifact/layer.ts:262-279`), so a boundary-excluding Area drawn around a shadow-hosted card would read "A drawn area enclosing nothing the artifact owns" (`src/ui/artifact/layer.ts:278`) about a card visibly inside the rectangle, and the operator would have to learn an implementation boundary before drawing. Crossing costs no control, no mode and no sentence — and in a saved-HTML artifact the question is moot, since `frame-src 'none'` (`src/artifact/fidelity.ts:224`) means no nested frame can exist there, so the crossing case is proxied applications only (`src/artifact/fidelity.ts:243`; the frame-src lines are 224 and 243 in the tree, not 167 and 181).
BOLDER: Make the Area the escape hatch for the whole class. Where a boundary cannot be descended at all — a closed shadow root, a cross-origin interior — the rectangle is still a truthful target: geometry, the crop, and no claim about the interior. The hard-limit class becomes pointable with a gesture the operator already has, and refusals are removed rather than added.

DECISION 4 — (a) Fold the frame path into the one existing address string; no new field, no version bump.
WHY: `runtimeState.address` is a bare string of one character or more under `additionalProperties: false` (`schema/envelope-v0.3.schema.json:255-263`), so folding is schema-valid as it stands while (b) is a v0.4 change that adds a field the agent must reconcile and the derived label must compare across. The layer already computes a nested document's address relative to the artifact's own base, because the proxy injects the same `data-address-base` into every proxied html response (`src/service/http.ts:1318-1323`) and `addressOf()` resolves `window.location` against it (`src/ui/artifact/layer.ts:184-192`) — only the ancestor chain is missing, so this is a composition, not a concept. Folding keeps `deriveResolutionLabel`'s single comparison intact (`src/resolution/model.ts:30-36`), which is what keeps the one state sentence the product owns (`src/ui/app.ts:2065`) true for a frame target; (c) loses control of that sentence entirely, because an under-recorded frame state can make the surface derive "deleted" (`src/ui/app.ts:2068`) about a target that merely sits in a frame's own state.
BOLDER: Make that composition the product's single address grammar — one string, compared identically at every depth — so the frame chain also travels into resolution and a frame target is re-found after a revision without the operator re-pointing. This leaves the unowned "Declared state beyond the address" item unowned rather than half-taken (`.scratch/backlog.md`, Evidence).
