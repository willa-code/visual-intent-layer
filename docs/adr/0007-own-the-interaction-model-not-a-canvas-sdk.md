# Own the interaction model rather than depend on a canvas SDK

The product will define visual selection, relational manipulation, drawing evidence, and Intent Previews in its own domain model. V0 will use the smallest product-owned browser interaction layer needed to prove user value rather than depend on tldraw or another general-purpose canvas SDK. External canvas engines may be evaluated as replaceable adapters, but their object formats and licenses will not define the Visual Intent Envelope or the open-source core.
