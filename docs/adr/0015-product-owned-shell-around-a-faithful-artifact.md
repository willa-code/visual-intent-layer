# Serve the review surface as a product-owned shell around a faithfully rendered artifact

The Review Surface stays a product-owned browser shell that frames the artifact rather than an overlay injected into the artifact's own document, because an injected overlay requires a browser extension for cross-origin applications, removes the boundary between review state and application state, and cannot be delivered to a host-neutral baseline; host-embedded MCP App presentation is deferred until a host actually supports it. To make the framed shell faithful rather than stripped, saved HTML is served with an injected base reference and rewritten relative and root-relative URLs, the artifact's own declared remote stylesheet, font and image origins are permitted while runtime data fetches stay blocked, and a local development server in Application Mode is reverse-proxied through the review service's own origin so its DOM is selectable rather than cross-origin and opaque. Opening a session launches the default browser on the machine running the service, with an explicit escape hatch for headless use, because handing a human a URL to copy is not a product experience.

**Amended by ADR-0020:** Application Mode is deleted as vocabulary. The same sentence now reads "a local development server in a proxied application", and the artifact type, not a mode, is what changes the serving and revision mechanism.

**Considered Options:** An in-page overlay injected into the artifact, which every comparable product uses, was rejected for now: it needs an extension for cross-origin applications, it puts review state and application state in one document, and it replaces a sandbox with a trust relationship. Host-embedded MCP App presentation was deferred rather than rejected; the local browser remains the complete experience under Baseline Compatibility, and the shell is the only surface that must be designed until a host supports embedding. Blocking every remote origin was rejected because an agent-generated artifact that depends on a CDN then renders unstyled, which was observed as a real fidelity failure rather than a theoretical one.

**Consequences:** ADR-0003 is amended. Local development servers are now proxied through the review service's origin, and a reviewed artifact may contact its declared remote origins. The local data plane, loopback binding, the no-implicit-upload promise and the exclusion of authenticated production applications are unchanged, but the security documentation must record both the proxy scope and the remote-origin policy, and the surface must disclose remote-origin contact before it happens. The shell chrome adopts a component layer and a real bundle step because anchored cards, drawers, dialogs, focus trapping, escape unwinding and roving tabindex are expensive and bad to hand-roll, while the artifact interaction layer stays dependency-free and self-contained because it executes inside the artifact's document under the artifact's own content policy and must remain small and auditable.
