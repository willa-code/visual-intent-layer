# Capture pixels only in the reviewing tab, and only when asked

**Status:** accepted

The envelope may carry a Captured View: a browser-composited image of the artifact as the Builder-Reviewer actually saw it, taken by a permissioned display capture in the tab that shows the artifact, cropped to the artifact rather than to the screen, never taken implicitly, and stored content-addressed like an attachment. A client-side rasterizer is rejected as a substitute: it re-renders from DOM and style data and returns blank for canvas and WebGL, cross-origin frames, closed shadow roots, and cross-origin images, which are precisely the cases a pixel record exists to cover. Shipping a browser to own the capture is rejected because a Chromium download is roughly 281 MB and contradicts the product's one-install promise. Attaching to the Builder-Reviewer's own browser over the DevTools Protocol is unavailable, because Chrome 136 stopped honouring the remote-debugging switches against a default data directory.

**Considered Options:** A headless browser of our own was rejected as the default rather than as an option; it is the most faithful path and the most expensive, and making it explicit keeps the ordinary install cheap. Rasterizing in the page was rejected as a *capture*, and is not retained as a fallback under the same name, because naming a re-render a screenshot is exactly the confidently-wrong claim the product refuses elsewhere.

**Consequences:** The artifact must stay rendered in the tab that captures it, which the framed Review Surface already guarantees and which rules out moving the artifact into its own window. The support statement becomes honest and narrow: Chromium desktop only, and one permission prompt per capture that cannot be persisted. `SECURITY.md` gains the capture permission and the disclosure, and the strategy brief's screenshot claim becomes this. Because no script can grant the permission, a Verification Run proves the control, the request and the stored evidence, and must report the capture itself as undriven.
